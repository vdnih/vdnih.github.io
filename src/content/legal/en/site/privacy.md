## What this site is

This is the portfolio site of vdnih, an independent developer. It introduces the apps being built here and hosts each app's privacy policy, terms of service, and support page.

For how a particular app handles your information, see that app's own privacy policy. This page is about **the site itself**.

## What this site collects

This site is made up of static web pages only. It does not:

- Run any analytics
- Serve advertising
- Set cookies
- Collect information through forms

Simply browsing the site therefore collects no personal information.

## About the host

This site is hosted on GitHub Pages. GitHub may record technical information such as visitors' IP addresses in its server logs, in order to operate and secure the service. That is not something the developer has configured, and the developer has no access to those logs. See the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement) for details.

## Links to other sites

This site links out to services such as GitHub, the App Store, and Google Play. What happens to your information on those sites is governed by their own policies.
